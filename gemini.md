# Project: Zero Grid Game

## Core Concept
A puzzle game where the player must reduce all numbers in a grid to exactly 0.
- **Grid sizes**: 3x3, 4x4, 5x5, etc.
- **Mechanics**: Clicking a cell reduces its 4 neighbors (Up, Down, Left, Right) by 1.
- **Losing Condition**: If any cell's value becomes less than 0, the player loses.
- **Winning Condition**: All cells in the grid are 0.

## Solvability Strategy
Levels are generated by starting with a grid of 0s and performing "Reverse Clicks".
A Reverse Click at (r, c) increases the values of neighbors by 1.
This ensures that repeating the same clicks in the game will result in a grid of 0s.

## UI/UX Goals
- **Style**: Premium, modern, dark mode with vibrant accents.
- **Animations**: Smooth cell transitions, victory effects, and menu fades.
- **Features**: Level selection, progress tracking, "Undo" button (optional but good).

## Tech Stack
- HTML5, CSS3 (Vanilla), JavaScript.
